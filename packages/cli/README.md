# @labafero/cli

CLI interna do Labafero Roleplay. Gerencia as dependências de resources do QBCore e o pipeline de build dos overrides Vue 3 sobre a UI nativa do QBCore.

## Comandos

- `labafero override:build` — compila os overrides Vue 3 mapeados em `labafero.json` e substitui a saída sobre os assets NUI nativos do QBCore correspondentes.
